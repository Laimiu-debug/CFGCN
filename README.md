# CFGCN · 四大名著网页游戏

围绕《西游记》《水浒传》《三国演义》《红楼梦》规划的网页游戏系列，共用官网入口、账号、游客流程及多语言支持。

目前处于设计与仓库初始化阶段，尚未选定技术栈，也尚未实现网站或游戏。玩法方向和未决事项以 Notion 设计页为准。

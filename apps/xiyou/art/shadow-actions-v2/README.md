# 西游皮影扩展技能库 v2

2026-10-20。用户要求扩充技能；本包保留 v1 的历史输出，使用 v4 原创人物和既有双手 / 支撑脚解算。人物、兵器尺寸没有统一缩放。没有消费 Tripo 积分或安装新插件。

## 内容与边界

- 90 项设计候选：五位主角各 8 项主动 / 兵器技、4 项被动；三类妖怪各 6 招；12 项队伍连携。每项含触发、目标、作用、限制、两条成长分支及组合。
- 58 项技能演员动作，其中比 v1 新增 34 项；另有 8 人受击与后撤，共 74 项全身动作。47 项技能另有移动上身遮罩。加 Idle / Walk / WalkLower / RestPose，八个 GLB 共 153 个片段。上身变体、被动与连携不再计作独立技能。
- 每人保留可编辑 `.blend`、16 个原创部件、单材质图集、实际导出的 GLB 和独立动作缩图。小白龙出鞘剑复用 v1 的原创图，未把剑鞘当作剑刃。
- 用户指出胳膊太细且被遮挡后，八人上臂 / 前臂按各自比例横向加宽 30%–75%，保持肩、肘与真实手心锚点；胸腹、后上臂、杆身、后前臂、前上臂、前前臂使用稳定深度层。原来出招时前后迁层已取消，备势 / 收势也不把整条后臂藏回胸腹后。预览可在完整人物与肩臂近看间切换；此版仍待用户视觉审阅。
- 根位移独立记录，短跃明确记录腾空区间；游戏必须按可达地面截短，不能穿墙 / 深水。虎妖踏地使用完整身体动作，事件来自脚部，不允许以走路下身替代落脚。
- 演练不等于实战：命中、冷却、AI、异常、分身、特效、成长、连携及地图实际接入均待实施与平衡。手部保留既有拳形，精细指法未完成。旧三维样板的四项同名连携没有因此完成皮影迁移。

## 查看

根目录运行 `node apps/xiyou/art/shadow-actions-v2/serve.mjs`，打开 <http://127.0.0.1:8879/>。技能册可以切换角色、主动 / 被动 / 连携、检索、翻面、逐帧、半速、暂停与移动施法；连携可打开参与招式的真实演员动作。

机制源为 `skill_book.py`，输出 `skills.json` 和根目录 `docs/xiyou-skill-library-v2.md`。动作源为 `catalog.py` / `author.py`，以 `shadow-actions-v1` 的作者工具和 `shadow-roster-v4` 的源骨架为只读依赖。原画、原始 Studio 资源与旧包未覆盖。

## 重建与检查

1. `python apps/xiyou/art/shadow-actions-v2/skill_book.py`
2. Blender 后台执行 `author.py`，使用 `--python-exit-code 1`；可在 `--` 后给角色 ID。
3. Blender 后台执行 `check.py`：重开原生文件、重导入 GLB，测实际透明轮廓的支撑脚、兵器地面、双手接点、端点、腾空窗口及移动遮罩，并测四段手臂不会退到胸腹后层。
4. Blender 后台执行 `render.py` 生成 58 张实际 GLB 接触姿势缩图。
5. `python apps/xiyou/art/shadow-actions-v2/prepare_preview.py`；界面复用共用设计变量与按钮状态。
6. `python apps/xiyou/art/shadow-actions-v2/package.py` 校验技能引用、缩图、事件接点、来源哈希并生成资源包。

验证证据集中在 `.local/qa/shadow-actions-v2/`。本机模型与浏览器检查分别记录，未将其写作游戏战斗录像或实体手机验收。未提交、推送或部署。

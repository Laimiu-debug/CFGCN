# API 基础

当前只提供健康检查，不包含账号、云存档、排行榜或玩家数据。

执行 `npm run dev:api`，默认仅监听 `127.0.0.1:8787`；可用 `PORT` 指定端口。官网开发模式代理 `/api`。`npm run preview` 为静态构建预览，不代理 API；门户与本地手记不依赖健康接口。

## 已实现

`GET /api/health` 返回：

```json
{ "status": "ok", "service": "cfgcn-api", "version": "0.1.0" }
```

`HEAD /api/health` 返回相同状态与空响应体。其他方法返回 405 及 `Allow: GET, HEAD`。不存在的路径返回 404。响应采用 JSON，带禁止缓存及 `nosniff` 头。

## 后续边界

浏览器手记 ID 不是认证凭据，不能用来授权访问服务器玩家数据。游戏成绩、货币和解锁由服务端校验，不能直接信任本地存档。

生产入口、域名及服务进程在后续部署中确定，沿用 Notion 部署页的服务与端口约束。

## 平面皮影制作约束

探索地图的图形继续遵守同源与可辨识要求，见 [地图标记与植被](xiyou-map-marks-and-flora.md)：地貌 / 水域 / 村居寺洞 / 林冠 / 草花分层，当前位置使用实际皮影头像，不能再只以正面树缩图和红点代替整个世界。未探索部分用可见墨雾遮住真实物件；个人旗标与图例、地图开关 / 删除 / 撤销都使用共用按钮和变量。低草、花、蕨丛可穿行，按群落布置并与同源地图匹配，不能用均匀撒花或连续草墙填满画面。

村庄群落按生活用途而非同一房屋均匀散点组织，当前高老庄样板见 [田庄与林木](xiyou-gaolao-map.md)：主宅 / 小院 / 田边草舍、可穿行庄门、留缺口的短竹篱、田畦与杏树 / 柳竹共同布置。田畦与地图图形同源，不能为了丰富物件封住横向探索；新画稿继续沿用已认可笔触、原型来源和 Blender 可编辑流程。

地图岸线与岩坡继续精修，见 [河岸表面实现与验收](xiyou-bank-surface.md)。地面 / 水面 / 角色脚点共用 0.5 / 1 / 2 米地理采样和接缝三角形，岩坡笔触采用按法线加权的三向投影；不能只模糊岸边或给陡面贴俯视纹理来冒充自然地貌。已接收原画与 Studio 来源保留，程序地形明确作为基础。实际画面、怪海和手机硬件分别验收。

地图阶段已接入首轮水墨布景，见 [水墨地图样板](xiyou-ink-world.md)：既有 Tripo 场景模块投影、原创水墨修绘、Blender 共用平面布景与淡设色地表结合真实地形；这是一种可运行的承载样板，场景最终形式仍待审阅。树石根部 / 石脚与碰撞布局共源，附近水线与实际河道共用参数，水面需要明确区分深浅，不能以留白隐藏不可走区域。当前样板沿用既有共用色板，官网、其他人物、妖怪、技能与全系列场景尚未完成水墨迁移。

寺观 / 洞府外景继续按同一笔触与空间规则制作，见 [黑风山地图](xiyou-heifeng-map.md)。开口山门、钟亭柱间必须真能穿行；闭合门扇用可见实体表达阻挡，不能以开放黑洞画稿配无形墙。屋顶、柱脚、门扇和入口比例在实际镜头中核对，原画导出与通行测试不替代美术审阅；宗教建筑按文学游戏改编标明，不把任意叠层飞檐当成历史复原。

河岸组合见 [鹰愁涧岸线](xiyou-riverbanks.md)。岸柳、芦苇、卧石依真实弯曲水线和岸侧疏密分组，深浅水 / 浅滩仍可辨；低矮草丛可穿行且不套高树阴影，树根与石脚保留对应实体。禁止用均匀连续的芦苇墙或树墙替代岸线，根点、实际尺度与地图缩图继续共源。

首四区地标继续采用同一方法，见 [地标样板](xiyou-map-landmarks.md)。建筑与大石需在实际到达视野中看到完整主要轮廓、入口和脚点；入口前的树石必须一起让行。平面布景按可见柱脚 / 石脚设置实体范围，透明拱口可穿行，不得以整幅画稿矩形制造空气墙。比例、镂刻和近远细节仍以游戏镜头与手机样板审阅，不能由图集导出通过替代。

村居样板见 [地表与郊野村居](xiyou-hamlet-and-ground.md)。村落需由道路、院子、房屋、树木与生产 / 生活痕迹组成有用途的空间，不能用两栋孤立房屋代替整体布置。现有画稿可复用，但需控制固定纹样重复、坡面拉伸及细行列闪烁；静态菜畦可合进地面，明确区别于独立模型和交互种植。参考原型的变形或植物形态需修正并记录，不将偏棕榈的树直接当作中国垂柳交付。

Tripo 可以作为三维原型来源，最终皮影片在 Blender 制作：先确定侧面设计与分层关系，再按头、躯干、上臂、前臂、手、腿、脚及兵器拆片；每片保留清楚轮廓、镂刻与设色，以平面网格或极薄片体、关节枢轴和稳定叠放关系构成角色。可从 Tripo 原型正交投影取得轮廓 / 纹理，再重建皮影片；不直接把完整人体沿一个轴压扁，以免前后肢、五官、衣物与兵器重叠。

皮影动作以部件绕关节转动为基础，仍须有起手、发力、接触与收势。Tripo 普通自动绑骨和动作不能直接当作皮影专用动作已完成。方向切换须检查非对称服装、文字、持械手和前后遮挡，人物移动时不得因朝向变化薄成看不见的边缘；具体多方向方案尚未定稿。

## 人物与动作

早期普通成年角色约 5.5–6 头身只作为历史制作参照，不能套给所有人物。现以各角色独立体态和同镜头剪影比较为准，保持面部、手和兵器在游戏镜头下可读；同一面部与材质处理沿用，共用骨架比例不作为要求。具体角色通过整装并排样板验收后定稿。

每个角色交付正侧背造型、色板、服装层次、兵器和剪影检查。模型生成参考图、Tripo 提示词、Blender 修整和引擎材质都遵循同一规范。AI 输出先检查风格、比例、拓扑和权重，再进入运行资源目录。

动作以角色性格和技能为依据。战斗动作有起手、接触、发力和收势，脚底有接地感，兵器轨迹与实际伤害时机相符。共用待机、移动、受击和救援规范；棍、耙、杖、诵经与马匹动作分别制作。功能反馈在减少动态设置下保持可读，装饰性摇摆、震屏和频繁闪光随设置关闭。

## 场景与镜头

统一风格化三维体积、柔和主光、偏冷环境光、稳定投影和有色远雾。地面、人物和近景之间有清楚的明度分组，玩法路径先于装饰密度。石道、城墙、木构、水体、山石和植被使用共同的细节尺度与材质处理。

同一玩法采用稳定的俯视斜角和角色屏幕尺寸，按桌面与手机调整视野。不同游戏可以根据战棋、经营和动作需要安排镜头，人物比例和渲染语言保持一致。建筑、树冠和特效应让出重要角色、目标、危险范围和交互点。

### 西游实机资产与特效的执行细则

2026-10-19 用户再次否定场景、UI、技能图标、技能动画与范围指示的风格。配色、圆形和去底板属于界面整理，不能单独证明工笔重彩与青绿山水达标。以同一战斗镜头同时审查人物、地景、HUD、法术与危险边界，画稿生成与代码检查均不能替代实机审画。

本轮改用真正的重彩器物插画，按经卷 / 袈裟 / 莲华、铁棍 / 定身 / 毫毛、马蹄 / 白龙 / 龙鳞分别建立辨识度；连携保留同笔触的组合器物。常驻界面继续透明，不重新添加方形提示底板。小地图使用山形皴线、细水纹与中式檐角，进度以轻量笔痕呈现；按钮状态、焦点和可访问名称继续共用既有规范。

三位角色的主动技有独立骨骼动作与收势；法术用莲华、云尾棍风、青绿水纹和丝带连携表达。红色危险圈外缘必须对应实际半径，内侧墨色与倒计时可变化，外缘不能随蓄力缩放而误导。相同计时驱动法术、动作和暂停 / 升级冻结；减少动态保留关键预警，关闭装饰性水纹推进和大幅转动。二维画稿、材质平面与碰撞基础不是需要 Tripo 建模的实体模型。

# 第一轮工程与视觉基础

日期：2026-10-18（Asia/Taipei）。提供真实可运行的官网与世界预览。

2026-10-19 用户进一步要求四款与官网严格统一，覆盖所有素材、页面和按钮；执行标准见 [四大名著统一美术标准](art-direction.md)。共用变量与 Button 组件、代码约束、iframe 主题同步现已作为后续开发入口，各作品仅在统一体系内表达时代与故事内容。

- [Sac 的小王子项目](https://x.com/Saccc_c)对应 [littleprince.dev](https://littleprince.dev/)。本轮核查官网启动页源码和主视觉，学习统一美术、安静入口、多语言与加载反馈。源码使用 Unity/WebGPU 加载器；浏览器访问超时，未完整实玩其 3D 剧情。
- [PokeBonk Online](https://pokebonk.online/#play)的游戏 iframe 指向 `https://pokebonk.com/?lang=en`，为第三方入口。学习清楚的进入路径和操作说明，第三方描述不当作正式游戏机制或完整实玩证据。
- 原有 Notion 中对 PokeBonk 账号、成绩和存档的整理继续作为待验证参考，不据此声称本项目已经实现。

参考站的图片、角色、模型和代码未进入产品。四幅原创插画用于视觉预览，尚不是可操作的 3D 场景。

## 应用与技术边界

`apps/website` 负责门户、语言、游客手记和导航。四款游戏各有 `world.ts` 元数据及独立异步入口，未来各自扩展运行时。`packages/shared` 保存类型、语言协商与数据接口；`packages/ui` 保存设计变量、图标与当前共用世界预览。

本轮采用 npm workspaces、React 19、TypeScript 5.9、Vite 8。API 使用原生 Node.js HTTP，当前仅健康检查。各游戏引擎尚未选定。

四款玩法不同，共用代码按实际复用抽取。账号、云存档、成绩校验和排行榜需要另行实现与验收。

## 真实交互

首页标签切换四个场景，“探访此境”进入世界预览。卡片和预览可收藏世界；手记可设游客名字、减少动态、查看收藏并导出 JSON。

名字、收藏、到访世界和设置保存在当前浏览器，刷新后保留。“到访”仅代表打开过预览，不代表完成游戏。

音乐使用用户已授权生成的三首 Runway 水墨国风短曲，环境与游戏音效复用本地原创素材，通过同一个 Web Audio 控制器播放；默认关闭，需点击开启。主界面有首次开头与单独编辑的重叠尾音循环段，探索 / 战斗平滑切换，游戏暂停与后台共同暂停，关闭后释放上下文。来源、循环参数与当前接入范围见 [声音接入](game-audio.md)。简体中文、繁体中文、英文覆盖官网、世界元数据和手记，优先保留手动选择的语言。

## 数据约定

- 游客资料键为 `cfgcn:traveler:v1`。损坏或受限存储不阻止进入，写入失败会在手记中提示。
- 存档键为 `cfgcn:save:<gameId>:v1`，含版本、游戏 ID、时间和载荷。目前提供接口，不创建虚假的游戏进度。
- 读取拒绝未知版本、游戏 ID 不匹配及无效时间，不删除原始存档。写入拒绝超过 1 MiB 或不可序列化的载荷，保留旧记录。
- 云端认证、游客转账号、冲突合并及服务端成绩校验尚待实现。

## 视觉与可访问性

大图承载情绪，文字与按钮保持清晰。图像使用 WebP 及卡片尺寸；不加载模型或游戏引擎。字体自托管，许可证随站点提供。

窄屏使用两列世界选择与书卷卡片。原生 `dialog` 支持键盘关闭和焦点约束，图标按钮保留可读名称。动效响应系统减少动态偏好与手记设置。

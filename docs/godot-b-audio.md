# B版声音接入西游／水浒 Godot 主工程

2026-10-24。用户已明确采用四段对比中的B版，授权接入两作Godot主工程并先本地测试。本批复用已制作的《云途初行》《义行山水》及8个短音效和必要旧声源，新增Runway调用和积分均为0；此前素材制作27积分原记录保持。原MP3、提示词、旧42件和完整曲库不覆盖。

## 当前接点与归属

音频唯一源为 `packages/godot-game-audio/`，`python scripts/audio-desktop-adopt/sync.py` 同步到两作各自的 `game_audio_b/`。两作 `project.godot` 只新增 `CFGCNAudio="*res://game_audio_b/host.gd"` autoload；默认仍为共用 `res://shared_desktop_ui/desktop_boot.tscn`。西游原 `scripts/game_audio.gd` 是兼容桥，保留原configure／update_state／reset／pause／effect／report及Boss模块所用接口；水浒直接订阅已有的 `game_audio_event`。本批不写两作主玩法、主场景、共用桌面UI源及运行副本。

正式制备源在 `source/audio/godot-b-v1/`，38件全局资源；西游预载37件／31,823,897字节，水浒23件／29,109,368字节，原生 `.res` 为压缩容器，B版WAV内部PCM逐字节保持、旧原生资源直接复制、UI原MP3数据保持。每作只引用自己的主题，水浒不加载西游既有技能短句。每作通过显式 `preload` 纳入导出依赖，资源与正式源逐SHA核对后共用硬链接；逻辑字节不能当作物理簇新增量。

音频清单、接点与运行脚本SHA见 `.local/qa/godot-audio-b-v1/main-integration.json`。旧接点和旧音频测试先保留在该批 `before/`，早期缺少paused／dropped兼容属性的失败日志保留；最终原生检查无脚本错误、引擎错误或退出资源泄漏警告。

## 循环、情绪与混音

| 用途 | 西游 | 水浒 |
| --- | --- | --- |
| 默认菜单／初行 | 唐风文学意象，琵琶／阮／筝／笙，完整主题从头进入 | 宋代江湖意象，阮／琵琶／筝／皮鼓／木击，寨中保留留白 |
| 交锋 | 真实Boss情境切至52秒段落 | 实际战斗切至42秒段落 |
| 战后／整备 | 实际恢复／战后切至125秒舒缓段，14秒后回行路 | 实际结局切至120秒舒缓段，回寨延续音乐 |
| 完整首遍 | 173.420秒 | 159.470秒 |
| 后续循环 | 2.400—173.420秒，周期171.020秒 | 2.400—159.470秒，周期157.070秒 |

主题是先前B版的文学与时代配器意象，未声称历史乐器复原。2秒升余弦衔接保留完整长曲，原生WAV按采样循环，不用短片定时重播。情境改变使用1.6秒等功率交叉淡变；相同情境不从头重启，快速连续转场只保留最新待切请求，最多两个音乐播放器。菜单、加载、玩法重建共用一个持久音频宿主。

音频自有池为2音乐＋8音效＋1既有短句，音效限频、优先级抢占，危险／既有短句短暂让音乐退后，Master有限幅余量。当前西游主工程另有2个Boss预警保留槽，因此不是全游戏仅11个播放器；桥将其warning来源指向B版木质预警，宿主同步其暂停和静音。播放变体不消耗玩法随机数，日志与事件去重有固定上限。

Master／Music／Effects／Voice沿现有共用设置保存，保存、取消回滚、重启、独立零音量均保留。菜单暂停和实际升级暂停冻结播放进度；静音期间消费事件基线，恢复不补播历史出招。主音量0使音乐游标暂停并清单次声音，Music0只暂停音乐，Effects／Voice分别停止对应尾音；用户存档和音量仍各用原接口。

## 真实事件范围

西游按实际释放／新的伤害笔触、目标HP、己方HP／护身值、经验／等级与真实七蛛warning进入触发。棍风与接触分开，水剑独立；只有护身消耗用克制法术反馈，真实HP下降才用衣甲受伤。读取、传送、规则时钟倒退或暂停时重建基线。沿用既有经声、耙、铲和已授权技能短句，不新增角色对白。

水浒使用主工程已实现的临时呈现事件 `action_release`／`reaction_release`／`step`／`attack_miss`／`shield_contact`／`attack_contact`／`downed`。出手按真正释放点，未中只有释放声；盾牌仅按实际shield_loss，金属／布皮根据真实body_id／helmet_id，未用护甲数值猜材质。新核心实例会重置有限事件去重，事件编号不入存档。旧combat_rules=1只按真实HP／护甲差保留克制反馈。当前M01样本没有自然覆盖所有弓／盾／金属甲事件，不把独立音效池诊断当作真实战斗覆盖。

## 退出清理与共用菜单声音接续

共用菜单负责人回归发现快速退出时原生WAV尚留播放引用，本批已在唯一音频源修复：退出停止所有自有／已登记Boss播放器，清空stream与信号引用，最终退出给驱动一次100毫秒的有界清理时间；普通场景切换无该等待。两作无头设置各20项、各无头快速退出／GPU兼容模式快速退出，共6个独立进程的完整stdout／stderr均无ObjectDB、资源占用或错误／警告；早期仅stop/clear未排空的失败日志保留。

共用UI真实接口为 `/root/CFGCNAudio.ui_event("ui_confirm")`，同接口支持 `ui_cancel`／`ui_hint`／`ui_error`，沿用本套既有确认／取消／木质提示，统一Effects及Master偏好；未知事件、静音及限频返回false，不补造替代声。界面限频使用独立真实单调时间，游戏／音乐时钟在暂停时保持冻结。现共用菜单负责人已按接口接线，本批在两作实际暂停菜单往返设置连续确认，连同原生总线／静音诊断各10项通过；音乐与规则未推进。接口源码与调用说明在 `packages/godot-game-audio/README.md`。

显式退出可先 `await audio.prepare_shutdown()` 再quit，排空3个处理帧，兼容没有独立驱动线程的离线MovieMaker。MovieMaker直接即时quit的早期失败录制保留日志，最终两作API／暂停菜单电影检查采用该真实退出接口且无退出错误；未以忽略stderr当作通过。长循环与前述实机录制在本次退出／UI限频补丁前完成；本批保持播放／段落切换函数逐字一致，并在最终源码另做本节回归。

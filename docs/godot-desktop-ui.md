| 采用点 | 共用层落点与试作边界 |
| --- | --- |
| Mask reveal／Stagger／Easing（#005／#002／#009） | 标题／笔触作约0.24—0.32秒的克制揭示，菜单文字可间隔约0.04秒进入；保留原画主体与留白。只在真正进入界面时播放，调整窗口、刷新进度或恢复焦点不重复进场；文字及命中区不随弹性拉伸。 |

分镜与动作衔接另参考 Toonflow 的连续性方法，游戏行为迁移参考东方重建方法，来源及适用边界统一记在 [迁移学习记录](godot-desktop-migration.md#github星标学习与迁移采用点2026-10-24)。现有194项功能验收保持为历史基础；本批只完成阅读、采用点整理及主工程对接，没有把新动效、游戏美术或音乐标为已实现。

## 根节点接口 v1

| 接口 | 责任 |
| --- | --- |
| `desktop_get_state() -> Dictionary` | 只读状态，供菜单开局前的未入树probe和游戏中调用；不写盘或开局。返回has_save、can_save、save_summary、save_path、pause_locked，可提供slots、can_import、has_unsaved_changes和保存不可用原因。 |
| `desktop_start(mode: String, path: String = "") -> Dictionary` | new／continue／load；返回真实ok/message回执，失败保留原档。新开前如会替换进度应先按游戏规则备份。 |
| `desktop_save() -> Dictionary` | 真正持久化后的回执；失败不宣称已保存。 |
| `desktop_set_menu_paused(paused: bool)` | 只增减菜单暂停原因，保留升级选点、战斗结算、失败等其他原因。 |
| `desktop_apply_settings(settings: Dictionary)` | 让玩法HUD、减少动态及游戏特有设置使用传入值；窗口、音频总线、InputMap和设置文件由共用层维护。 |
| `desktop_menu_requested` 信号 | 无参数；玩法HUD发出后，共用层开启暂停菜单。 |

slots为{label,path,summary}数组。若有有效has_save和save_path而未提供数组，共用层生成本机进度行；文件导入只在can_import=true时显示。关闭菜单不隐式选择升级卡。

`games/<game>.json` 是源配置，生成的 `game_data.gd` 是实际运行依赖；字体、封面和笔触也有显式资源依赖，避免导出漏掉普通JSON文件。水浒 `start_modes.new=new_game` 按最新主工程接口进入180钱48粮的寨中整备，先预载实际河景；原生演武由主工程 `new_drill` 模式继续提供。主工程未完的六卷战役／108完整技能／旧M15转换不由菜单替代；水浒存档选择与导入说明明确限于当前Godot寨中／演武档。

共用入口在实例入树前设置metadata：desktop_shell_managed=true、desktop_start_mode、desktop_save_path。受管模式避免提前自动续档或推进；ESC与窗口关闭交给共用层，不另一路绕过保存失败直接退出。原场景独立调试可保留原处理。

菜单暂停临时停用玩法根节点process mode，关闭恢复原值，再解除游戏内部的菜单暂停原因；不全局停用共用UI。游戏存档格式、身份、永久义册／当局生死、战中动作与旧档转换由各主工程实现。

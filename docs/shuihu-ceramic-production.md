## 脸部标准

- 眉形可辨，独立于上眼睑；粗眉、细眉、长眉与眉势因人不同。
- 上下眼睑有形体，眼白、虹膜和瞳孔可读，不能糊成黑眼窝或空白陶面。
- 鼻翼 / 鼻孔、嘴唇分界、胡须与鬓发边缘清楚；不以粗黑线覆盖全部面部结构。
- 保留脸型、年龄、皮肤施色、神态、胎记和须发差异；宋江 / 李逵等深肤色与关胜红脸用哑光化妆土 / 设色表达，不将所有人统一素白脸。
- 在中性灯下检查正面与左右四分之三脸部近景，并在实际网页放大 / 平移 / 部位定位中复核；只看全身缩图不能验收眉眼。

## Tripo 与 Blender 的分工

Tripo 负责有来源记录的初始雕塑形体与纹理，采用当前已有 Studio 会员。先按 168 人本体和 54 类独立器物提交，逐项保存实际输入、项目、报价和原始模型哈希；不额外购买 API / 会员，不将提示词中的预算当作实际面数。

生成后还需要 Blender：

1. 查破面 / 穿插 / 多余肢体与衣甲粘连，修头脸、眼睑、鼻口和手指；眉眼仍模糊的补绘贴图，必要时局部重建，保留个体面容。
2. 人物手掌完整，兵器是独立刚性物体，校正数量、形制、左右手和握点；扈三娘双刀、鲁智深杖与林冲枪端逐件复核。兵器物体变换不代表手臂已有挥砍。
3. 校正素胎与衣甲釉面，零金属釉面、合理粗糙度与积釉；不把生成贴图上的白高光当作真实釉面，也不让镜面反光盖住眉眼。
4. 校正姿态、真实毫米尺寸、脚点与底部轴心，保存可编辑 `.blend`；不整件纵向拉伸人物来伪造体态。
5. 保留精细源、输出图鉴高清件和战场 LOD，检查 UV / 法线 / 材质 / 贴图，导出 GLB 后重导入，再在网页中检查缩放和平移近看。该阶段的具体面数 / 包体须据实物确定。

不绑骨不等于免精修，生成完成也不是可直接入游戏。分别记录排队、已提交、已生成、已下载、精修、图鉴导出、战场导出和验收。

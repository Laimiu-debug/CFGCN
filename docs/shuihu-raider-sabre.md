## 来源与动作

保留原身体、完整脸和双掌、三角面、每角 UV 及有效贴图像素。衣装沿原连续网格作权重过渡，左臂保留原姿态随躯干；右臂采用共用中性腕求解器，轨迹沿来源肘弧。先做来源姿态预检后才导出这一份模型，没有把试姿算成多个模型版本。`plan.json` 保留最初方案，最终实际解法、柄部变换和来源 SHA 以不可变 `raider.json` 及冻结验证记录为准。

来源静态握点原建议轴与真实掌孔不同。本批从实际原皮肤表面拟合 C 孔，不将袖口当手，也不以代理手掌替换原件。原单刀重新定向，只有柄／刀首径向适配（比例约 0.1822—0.4082），刃体和过渡外护手保留；不能宣传整把刀几何未改。原组件坐标帧与当前独立运行刀具相符，最大矩阵差约 1.35e-9；未用简化前后相同 UV 推断刚体对应。150 个来源姿态采样人体／刀具交叉 0，刃领先最低余弦约 0.703，自己完整头部与刀刃包络最小距离约 5.73 显示毫米。

GLB 和可编辑稿分别独立重开，共 108 个姿态采样；10 骨／6 片段、原头掌刚性及刀体避让通过。身体 30000 三角面逐角位置、UV 和纹理有效像素保持，原单刀 UV 和有效纹理像素保持。导出采样器提示保留，并另核有效像素，不把日志无报错当作美术终审。上述显示毫米以约 70 毫米陶塑来源计。

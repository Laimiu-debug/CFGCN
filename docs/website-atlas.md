# 山河地图首页与长安入口样板

当前正式版本已改为用户确认的细笔水墨 v3（2026-10-20），见本文末“退回版成为正式首页”和部署文档最新记录。以下早期三维模型实现与返工记录保留为历史，不代表当前主域首页。

2026-10-19，用户授权本机样板，并明确要求相对地理位置正确、尽量不用生图制作网站美术、打开即进入有生命感的世界、尽量少文字。

## 当前实现

- 官网首屏为 Three.js 实时三维地形，四城、民居、松石及成片山脊、森林、田园、河岸、梁山湿地和江南竹园均使用 Tripo Studio 生成并经 Blender 修整的 GLB。河面与云采用实时着色器效果，旗帜和舟船仍是早期几何样板；没有采用初次生成的山水 / 城门图片。最新区域分布、声景与验证见下节，保留首次城镇交付记录。
- 经纬度统一定义在 `apps/website/src/atlas-geometry.json`，高程、河流和所有城镇使用同一北向坐标。长安约 108.94 E / 34.26 N；汉中 107.03 / 33.07；梁山 116.09 / 35.80；金陵 118.78 / 32.06。是区域代表点，不宣称精确古城坐标；红楼为架空文学入口。汉中在长安西南、梁山在长安东北、金陵在梁山东南。
- 高程使用 Mapzen / AWS Terrain Tiles 的 12 张 z5 Terrarium 数据，抽样为 193 × 113 北向网格，运行包 43,618 字节。垂直高度按 0.005 场景单位 / 米艺术夸张，经纬度不随美术调整。原始缓存及来源哈希在 `.local/references/atlas/terrain/` 与 `terrain-manifest.json`。
- 河流 / 湖泊 / 海岸线来自 Natural Earth 1:50m；预处理为本地几何。当前浏览器无须访问地图服务或付费 API。`scripts/build-atlas.mjs` 构建矢量数据，`scripts/build-atlas-terrain.mjs` 下载、校验和抽样高程。Mapzen Terrarium 的解码为 `(R * 256 + G + B / 256) - 32768`，原始 Mercator 瓦片正确重采样至同一经纬度网格。
- 用户反馈首轮地图过空、城镇过假后，本轮已实际用现有 Studio 会员生成长安街坊、汉中关隘、梁山水寨、金陵园林和可复用民居，替换原程序化城镇。既有 Studio 松石另做远景 LOD。保留原始来源、提示词、哈希与可编辑源文件；建筑为故事意象，风格和文化细节仍待用户审阅。未在本轮增加四作人物。
- 城镇周围增加近郊民居、田地、随地势弯曲的道路和成片松石；原地理锚点不动，基础周围局部整平并平滑接回 DEM。民居与松石用实例复用，远景松石改用统一黛绿材质减少细纹闪烁，长安近景保留贴图。田地和路面是沿高程采样的地面表面，不冒充 Tripo 建筑。
- 地图支持鼠标 / 单指拖动、滚轮 / 双指缩放及共用 Button 的放大、缩小、一览全图。拖动超过阈值不触发进游戏。桌面默认全图，窄屏先近看长安，可拖向其他区域或一览全图；屏外标签不进入键盘顺序，底部四个入口始终保留。
- 鼠标移到三维城镇或其标签会显示篇名 / 时代简短提示；点击城镇、标签或底部可访问入口可进入。触屏直接射线拾取，键盘原生 Button 焦点提供同样提示。三语入口完整，其他三作如实保持世界预览。
- 长安由地图进入同一 Tripo 城景的斜向近景，保留约 4.2 秒实时镜头。城景模型首帧先呈现，再启用游戏载入；按实际渲染帧推进演出，限制长帧增量，避免 WASM 初始化阻塞时直接跳到演出末尾。真实 ready 后才启动已有旅程或新旅程，playing 回执后才移走遮罩。跳过演出不会跳过加载，失败可重试或返回。原菜单与直接游戏入口保留。近景周边单独艺术化整平，门户地图经纬度不变。
- 本机以 hash 路由衔接；已配置的生产子域通过 `arrival=changan`、语言和减少动态参数衔接入口，结束后移除临时参数。主域不直接读取游戏子域存档；继续旅程由游戏读取自己的有效本地检查点。
- 首页移除大标题、长段介绍和卡片。保留品牌、语言 / 手记、四个城镇名字、短状态和减少动态。所有颜色 / 材质从统一 tokens 读取；控件使用共用 Button。
- 场景限制 DPR 与约 30 FPS，隐藏页停止渲染；离开释放几何、材质、渲染器和 WebGL 上下文。减少动态停下云、旗、舟、水面光点和镜头摆动，并跳过镜头飞行。WebGL 不可用时提供地理矢量与可访问的四个入口。

## 连续山河与淡墨融合（2026-10-19）

用户反馈上一版仍像把模型摆在地图上，上下空白、云不明显流动、水面刷新异常。以下为本轮本机改进，保留前面版本的交付 / 验证历史。

- 官网地图改为覆盖整个视口，页头浮在世界上方，移除画面上下的白色渐隐。核心 DEM 边界以匹配顶点接出地形与复用 Studio 远山林地；这些范围外景物仅为装饰性延伸。四城锚点、真实水系、故事的地域差异均保留。
- `atlas-ink.ts` 为现有模型、地面和边缘地形共用黛绿 / 纸绢淡墨处理，压低贴图饱和度和塑料反光。地景底座下沉、边缘土色融合，山体横向连片、纵向压低并调整走向，避免整齐的展示地块；城市底层地面也回到共用土色。
- 地面高度贴合由 8 位提升到双通道 16 位，保留线性过滤，减少底边高度量化。实例按空间小组共享几何和材质，近看时可以裁掉远处山林；没有增加模型下载，也没有改写接收的 Studio 原件、blend 或来源哈希。
- 水面改为与 DEM 完全一致的单层网格。海岸、湖泊、河道和局部故事湿地合并成覆盖场，移除几十片重叠水泊及各自的纹理方向，避免深度竞争、分段条纹和三角扇穿插。水纹使用统一世界坐标，水岸柔和过渡；拾取同时检查覆盖，陆地不会误触水波。
- 云层提高到山峰上方，增加可见的平移速度和细雾层次，保留指针拨云。环境按可见墙钟时间推进，长帧不再把云、水、旗和舟一起拖慢；入场镜头继续按受限渲染帧推进，避免游戏加载时跳过演出。切后台重置计时基点，减少动态停住环境，恢复时不追赶暂停时间。
- 新增三项计时回归测试，分别覆盖慢帧、后台恢复和减少动态 / 恢复。最终 `npm run check` 完整通过：28 项 JavaScript 测试、33 项 Rust 测试、fmt / Clippy、地区 / 护送模拟、WASM 和官网构建。十二项原始 / 运行资源校验通过，模型下载仍为 5,391,708 字节。完整检查过程中曾遇到同时变更的西游场景格式检查失败，该文件后续更新后重新完整检查已通过；本轮未改动该游戏场景文件。
- 实际 Chromium 检查 1280 × 800、996 × 1244 实际窗口、390 × 844 与 320 × 760 英文。地图容器与视口等高、无横向溢出；实际窗口四城标签都可见，手机保留近看长安与缩远全图。检查原生拖动不误入、键盘缩放 / 城镇短提示、水面点击与陆地不误触、减少动态 / 恢复、长安进入运行中的西游 HUD 并返回；没有清空资料或游戏检查点。
- 云水环境两次真实画面取样间隔 11.332 秒，环境推进约 11.35 秒；第一朵云的世界横坐标同步变化。减少动态时环境计时和云坐标在交互检查中保持不变，水面绘制对象为一个。不能用这些数据替代用户对流云 / 水纹的观感判断。
- 桌面 1280 样本约 1.73 百万三角面 / 122 绘制调用，996 竖向实际窗口约 1.86 百万 / 134；390 近景约 1.05 百万 / 62，320 全图约 1.25 百万 / 98。包含延伸山林，按空间实例组裁剪；仅为本机 Chromium 指标，真实手机 GPU、帧时间和公网加载仍需独立验收。三维代码包约 199 kB gzip，仍有 Vite 的 500 kB 原始体积提示。

## 首页静赏与动态壁纸（2026-10-19）

用户希望首页无人操作时也能当壁纸欣赏。本轮沿用既有实时山河，先建立静赏构图和环境节奏；最终美术质量仍以用户实际观感验收。

- 场景模型首帧就绪后，约八秒没有操作，页头、城名、短状态及控件缓慢隐退。右侧眼睛图标可立即静赏。指针移动、按键或轻触唤回；隐退控件使用 `inert`，不会保留隐藏焦点。首次唤回触按消耗对应点击，长按及同次多指唤回不直接进入隐藏城镇；再次主动点击正常进入。

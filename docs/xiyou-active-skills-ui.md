## 界面与画稿

- 战斗：透明布局，圆形头像、气血细线 / 外弧、四个插画技能、出招进度与数值冷却；绝技用旧金饰点区分。独立闪避与四式分开。说明收进招式簿 / 悬停，常驻区没有任务矩形底板。
- 整备：实际 GLB 导出的五人完整立绘、十二式图形目录、四槽选择、当前作用 / 限制与冷却；窄屏省去立绘，保留十二式和详情。内部滚动让完成按钮始终可见。重复装备交换位置，不刷新冷却。
- 暂停：四式预览、继续 / 整备 / 重开 / 返回，提供会记住选择的减少动态设置。入口、旧章回菜单与探索地图控件沿用同一套纸墨、青黛、旧金和朱砂；地图正常遮挡与标记等功能保留。
- 五张专属绝技插画通过内置 `image_gen` 生成，原图与完整提示词在 `apps/xiyou/art/shadow-ui-v6/`。运行五图共 278,094 字节；仅标准缩放 / 编码，没有把人物姿势缩图当大招图标。普通技能复用既有原画，并按招式组合兵器 / 曲线图形；部分仍共享原画母题，未宣称六十张独立新绘画。
- 白龙运行特效使用同源透明龙形画稿，跟随实际碰撞弹道；其他四招以共享原生曲面、棍体、莲瓣、九齿、浪峰和碎笔组合。全场仍共用 192 个特效实体上限，危险预警优先；不新增友方满地范围圆或强制镜头震动。

原生动作位于 `apps/xiyou/art/shadow-actions-v6/`；v5 原件保留。每人仍十二招，五招升级没有虚增至六十五招。八个 GLB 实含 200 片段，包括 94 全身、74 上身和 32 基础；六十招都有移动上身层。角色体态和双臂沿用 v5 修订，仍待用户视觉审阅，不能称已全部解决造型问题。

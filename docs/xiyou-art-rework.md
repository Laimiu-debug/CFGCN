# 西游美术与山涧空间返工

2026-10-19。本轮是可运行的本地返工版本，最终画面仍待用户审阅；用户已否定此前平地重复摆件式场景，不把功能测试通过写成美术认可。统一标准仍为工笔重彩、青绿山水与有体积的绘本人物。需要真实的地形、光影和比例，并非仅更换配色。

## 实现

- 五行山、松风古道和鹰愁涧共用连续高度剖面，保留原区域、事件、共享成长、领队切换与伙伴 AI。山坡、谷地、弯曲河岸和水下浅滩具有实际高差。角色、敌人、拾取、弹体、血条、镜头与路标跟随地面；法术平面细分后在 GPU 贴合地形，水中关键范围显示在水面上。
- `packages/game-core/data/xiyou-terrain.json` 是地形表达式唯一入口；`scripts/terrain-profile.mjs` 生成 Rust、Blender Python 与 WESL。`art/world-props.json` 同时驱动 Rust 导航碰撞、可见树木和 Blender 投影烘焙。规则水域使用同一曲线，伙伴绕河寻找浅滩，不将渲染高度强塞进二维战斗距离。
- 自然岩壁和完整树冠来自现有 Tripo Studio 会员。原始岩壁先统一长轴、焊接再减面，山脚按覆盖范围最低地面埋入；使用少量连续大形，替换原来的独立玉雕式石柱。树木经体素重建保留叶冠体积、重新展开 UV 并烘焙原始 Studio 颜色；地被灌木从同一树冠提取。树冠暂为风格化阔叶形，尚非准确松针造型。
- 地面为原创起伏网格及有来源的低对比手绘纹理，烘焙树石的静态方向光投影与环境遮蔽。轻量绘本 shader 保留冷暖主光、法线体积、有色远雾；水面有深浅、岸边明度、透水和缓慢流纹。没有重新引入首开耗时的完整 PBR 材质图、实时阴影贴图或重后处理。
- 16 项真实重彩技能插画接入按钮和冷却；金莲、棍风云尾、青绿水纹和朱砂预警使用原画纹理与实例进度。危险圈外缘保持实际伤害半径，内部倒计时变化；连携用丝线和角色动作串联。共用纹理 / 材质 / 网格，不逐帧新建 GPU 资源。
- 唐僧、悟空和白龙马各保留待机、行走、普通攻击，并增加两项主动技骨骼动作；实际 GLB 有五段动画，基础构建脚本会追加这些动作。暂停 / 升级冻结动作、范围与流水时间，减少动态保留关键预警。HUD 保持无底板、人物头像、绘制图标与可访问名称，所有按钮沿用共用组件。

## 重建

使用本机已有 Blender 5.2，不需新增建模软件。Node 脚本执行原画切片 / 尺寸与格式处理，不重绘原图。

```text
node scripts/terrain-profile.mjs
node apps/xiyou/art/build-skill-art.mjs
node apps/xiyou/art/build-vfx-art.mjs
node apps/xiyou/art/build-ground-art.mjs
blender -b --python-exit-code 1 --python apps/xiyou/art/build_canyon.py
blender -b --python-exit-code 1 --python apps/xiyou/art/build_pine.py
blender -b --python-exit-code 1 --python apps/xiyou/art/build_painted_world.py
blender -b --python-exit-code 1 --python apps/xiyou/art/build_spell_motion.py
python apps/xiyou/art/check_assets.py
npm run check
```

`build_world.py` 和 `build_river_assets.py` 调用新的连续地形管线，旧程序占位资产生成器不得覆盖已接收的 Studio 模型。`npm run build:xiyou` 自动同步地形表达式及设计变量。

## 验证和边界

最终本地回归：38 项 JavaScript、35 项 Rust、fmt / Clippy、规则模拟、类型 / 美术约束、生产构建及 15 项 GLB 检查通过；六项主动技实际施放 / 冷却、边界和三语手机多指通过。真实 Edge / WebGL2 完成救援、入队、共享升级、领队切换、渡涧及回到五行山，区域顺序 1 / 2 / 1 / 0，事件 31；卸载 / 重载及刷新续玩正常。完整流程首次被正常升级选择打断，改为正常处理选择后重新跑通；没有修改气血、时间或事件来跳过游戏。

完整网页受控样本为 390×844、DPR 2、6 Mbps / 80 ms、4 倍 CPU 限速、独立新 Edge：首次约 16.775 秒，字节缓存重访约 2.278 秒。WASM 原始 26,042,235 字节、gzip 6,059,017，`client-51b946f38794.wasm`。地图分块为 792,484 / 954,036 字节；当前首开仍受通用渲染引擎体积影响，不能与此前不同条件公网 41 秒直接相减。不是手机硬件或公网部署成绩。

资产检查直接读取 GLB，核对面数、材质、动画、骨骼、权重、纹理、真实字节及可编辑源。地形检查额外要求烘焙色为可读的 `COLOR_0`、不能是白色占位色，逐顶点比较运行地形与角色高度函数；规则测试覆盖弯曲水域、可走浅滩与过区连续高度。

实机检查必须使用游戏页面、实际施法、换人、敌伤和过区，保存桌面与手机画面。现有 `.local/qa/valley-*` 为此轮证据；早期 `painted-*` 截图可能仍是用户已否定的中间场景，不能充当最终画面。

龙形首领与独行教学部分道具仍是旧暂代；松针形制、材质笔触、更多植被变化、完整西行世界和真实手机 GPU 仍需后续制作或验收。当前近景返工不代表四款游戏所有资产已完成，也没有提交、推送或生产部署。

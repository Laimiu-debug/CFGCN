# 河岸轮廓与岩坡笔触

2026-10-20，接续 [鹰愁涧岸线与植被](xiyou-riverbanks.md)，继续地图优先。保留统一水墨 / 平面皮影、无道路导向、探索留白与当前开发版画面优先；本批修整程序地形基础，没有生成、替换或压缩已接收的原画和 Tripo 资产。

## 原因与实现

此前所有地块使用 2 米网格，水面与地面的交界显出折线；陡坡保留过多俯投纹理，笔触沿坡面拉长。仅增加植物或模糊水边不能修正地形与人物脚点的关系。

- `packages/game-core/src/expedition.rs` 的 `MapGrid` 成为地面、水面和角色脚下高度的共同拓扑。64 米地块保持不变，实际水岸 / 水域使用 0.5 米采样，外侧缓冲为 1 米，干地区域为 2 米。密度由地理位置决定，不随镜头或帧率改变；保守河道包围范围内再用实际湿地采样判定，结果使用最多 96 项的缓存。
- 细地块边界索引收束到粗地块的同一顶点。修正角部折叠与共线三角形后，网格完整覆盖、不反向；角色在接缝使用实际三角面的重心插值，避免渲染平面与脚下查询各用一种近似。
- `apps/xiyou/rust/src/expedition_scene.rs` 的地面 / 水面共用上述顶点和索引，法线统一按正负 1 米的高度差求取，避免不同密度产生光照接缝。水深保留正负值，水墨水面 shader 按深度导数柔化交界；深水判定、浅滩、地形表达式与物件布局未因此改写。
- 岩坡使用按法线六次方归一化的三向投影，陡面优先侧向笔触，保留原纹样、尺度和设色。旧战斗水材质不套新水岸遮罩。
- 调试 HUD 仅在 `?survey-tools=1` 显示真实帧时间样本、地块建立 / 回收量。正常入口仍使用原透明图形 HUD，没有新增常驻方块说明。

程序地形不冒充新 Tripo 模型。对比固定 V21 与 V23，地面画稿、六组场景 GLB、地图图集和悟空共九项原资产哈希保持一致；本批没有 Studio 积分消费或软件安装。shader 与 WASM 是本次改变的运行文件。

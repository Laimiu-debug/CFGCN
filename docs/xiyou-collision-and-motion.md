# 西游场景碰撞与动作返工

2026-10-19。用户继续指出空气墙、布景不当和人物僵硬，否定此前画面的视觉完成状态。本轮保持统一东方绘本 / 工笔青绿、既有 Tripo Studio 原型、透明图形 HUD 和共用按钮；不将功能测试或性能通过当作最终美术认可。没有新购买积分、生成替代模型或安装软件。

## 已定位的原因

- 古道原本在 `z=40/59` 从 18 米半宽突然切为 8 米，再切为 13 米；地形则是另一条平滑坡线。开阔地先撞到逻辑边界，过线时还会发生横向推移。
- glTF 导入的岩壁物体处于四元数模式，原布景函数写欧拉角而没有切换模式，转向没有生效。放大的长岩壁横着侵入视野；高墙与硬宽度也没有共同占地依据。
- 封印石用 2.3–2.4 米圆盘碰撞，实物在窄方向只有约 1.7 米半径；河岸石块则是另一个布置表。树石、可见关口与导航需要统一来源。
- 骨骼位置是骨骼局部轴，原来的 `root.location.z` 并非世界向上，使预期身体起伏变成了前后滑移。唐僧缺少脚掌骨，旧腿部正弦摆动没有落脚目标。白龙马每 1.8 米循环一次，在正常移动和踏浪时步频过高。

## 场景与可走范围

`packages/game-core/data/xiyou-terrain.json` 是 Rust、Blender 和贴地 GPU 表面的唯一高度与轮廓来源。`valley_center/valley_width` 连续变化，形成弯曲谷地、较窄古道与河岸战斗空地；身体极限对应实际可见的陡峭石色坡脚，不在区域线另加宽度跳变。河道混合不能抹平侧坡，否则会在水面上留下无形边界。地图两端同样有可见坡脚，能够立即反向离开。

`apps/xiyou/art/world-layout.json` 保存石块、关口、岩壁的实际位置 / 朝向 / 尺寸与树石身体占地；`world-props.json` 保存树木布置。生成脚本产出 Rust 数据，运行场景读取同一份生成结果。封印、守山妖关口和教学末端分别控制可见性；移除旧的关口前 Z 限制。树木碰撞按树根 / 基石，不能把整个树冠当身体。现行椭圆是低成本身体占地，留 0.38 米角色半径；它不是精确网格物理，也不能直接套用到未来不同形制的模型。

岩壁复用现有 Studio 模块，改为沿谷地外围延伸、降低近景高度；导出前检查每个岩壁顶点都在可走轮廓外。坡脚另用共享地形形成，树石接地及静态投影沿用实际位置。不能再靠巨大前景模型遮住空地、角色和技能；桌面与窄屏都需检查实战镜头。导航范围覆盖全部现有可走宽度和末端，障碍查询使用与身体相同的旋转椭圆。

邻区提前到 `z=18` 预取，河岸回到 `z<12` 后释放；山地维持原有前取 / 远卸载。若邻区仍未就绪，路展进度可见，向未就绪地块行走时冻结战斗和时间，资源就绪自动续走；不能只锁一条方向而让妖怪持续攻击。持久缓存、存档与其他作品不受影响。

## 已有 Studio 人物的动作

`apps/xiyou/art/build_party_motion.py` 在已接收的 `.blend` 上重做五段动作，保护原始 Studio 文件和来源哈希；旧 `build_spell_motion.py` 入口转到新流程，基础模型重建后也不会恢复僵硬旧动作。导出的顺序继续为待机 / 行走 / 普攻 / 主技 / 辅技。

- 唐僧加入左右脚掌骨，鞋底与踝关节分配权重；双人各自使用脚掌 IK、恒速落脚、抬脚返回、骨盆承重、胸肩反向转动和随动衣带。
- 白龙马采用对角蹄组的行进节奏、躯干承重、颈首补偿和尾随动；施法以三蹄支撑、单蹄抬起替代两条前腿整体悬浮。
- 姿势先计算预备、抬手 / 挥棍 / 提蹄、释放和收回；手掌目标保持在手臂可达范围。世界位移先转换到根骨骼的静置轴，再写局部位置。
- Blender 与 Rust 共读 `motion-profile.json`：唐僧 3.2 米、悟空 3.6 米、白龙马 4.4 米一个循环，普通行进由实际距离推进；最高步频限制踏浪时的高速闪动。踏浪是幻想冲刺，限频后不宣称冲刺全程完全无滑步。
- 保留上身施法 / 腿部步态分层；起步约 0.10 秒、停步约 0.14 秒混合，转向保留短插值，伙伴接近路点时减速。暂停 / 培养冻结；隐藏骨架和零权重动画继续停止播放。没有增加普通敌人完整骨骼或取消怪海成本限制。

## 验证方式

`Blender --background --python apps/xiyou/art/check_party_motion.py` 重新导入实际运行 GLB，检查五段动作的形变、有限值、地面穿透、两只脚 / 四只蹄的接触轨迹。恒定落脚区间叠加约定前进距离后测量漂移，不能只检查片段名称或关节变化。现行导出脚掌的前后漂移约为唐僧 2.35 毫米、悟空 4.23 毫米、白龙马最差 3.78 厘米；这是平地导出轨迹，不是所有坡面 / 转弯的无滑动保证。

Rust 回归覆盖旧 `z=40/59` 两侧开阔地、整条石色边界、可见关口与撤除、伙伴绕石和所有旧剧情规则。实际浏览器用合法独立存档及正常按键检查侧路、开阔河岸、封印后通路、末端返回、延迟邻区的可见等待、三人行走 / 施法 / 转身、暂停、完整救人与无缝往返、手机多指。仅测试存档独立，不改用户行记。

画面变化后复测 200 / 500 / 1000 压力入口与 4 倍 CPU 限速样本。资源检查、工程检查和实际路线分别保留证据；桌面 GPU 限速不当作手机硬件。完整西行、真实手机和最终美术仍继续验收；最终数据同步已有 Notion 进度页，整体任务保持进行中，提交 / 推送 / 部署另行记录。

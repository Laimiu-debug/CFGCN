# 自由探索地图与村居林木扩充

2026-10-20，用户最新确认：现有房屋和树木画风可延续，但数量太少；场景不设道路，小地图更丰富，让玩家自行探索。当前开发版先完善画面与布置，暂不围绕加载速度压缩资源。本条覆盖旧样板的道路引导、全路线默认揭示和首屏 1.5 MB 制作门槛；旧记录作为历史保留。

## 本轮实现

- 地面删除道路材质遮罩及支路数据；树石不再沿主路或区域整条横线清空。`map_anchor_x` 只用于旧位置兼容、区域物件锚点及局部浅滩定位，不绘制道路或维持整条可走走廊。局部院落、可见入口与出生小片空地保留；深水、树根和房屋墙脚仍阻挡。
- 原两舍保留，新增茅舍、双层木楼和错落瓦舍三种房屋画稿，新增 27 栋实际建筑，首四区合计 29 栋。柳树、两种松形加上阔叶树 / 竹丛，形成五种可复用林木形体。增添手工林群和群落密度，屋侧、屋后与林隙提供绕行空间。河岸房屋的初次地基检查发现高差后，已移到干岸。
- 小地图读取 Rust 同源高度、水深及树石位置；树木、民居与地标使用真实场景画稿缩图。地势浓淡、断续等高线、水域深浅和实际物件共同表达地貌，没有路线、导航箭头或预先揭示的未来事件点。中心身体标记与上沿朝向刻度保留定位；地图坐标随实际镜头保持一致。
- 扩展地图可拖动、放大 / 缩小、回到当前位置，键盘方向键在地图中平移。未到范围留白，16 米空间格随行走揭开约 64 米周围环境，独立保存在 `cfgcn:map:xiyou:fog:v1`；不因一个区域位已访问就揭开整个区域，也不通过拖动地图发现地形。位置和旧战斗记录继续独立。
- 原 32 区制作定位放到显式 `?survey-tools=1` 调试入口。正常打开仅显示探索地图；调试定位不当作已设计的游戏传送功能。附近图块继续释放、资源哈希与存档校验继续执行；本轮不做冷启动 / 限网提速比较，不以减色缩图削减新增画稿。

## 制作与验证边界

来源、原画、五份完整提示词、可编辑 Blender 和重导入记录见 [资源说明](../apps/xiyou/art/ink-settlement/README.md)。代表类别沿用已接收的 Tripo Studio 原型；新图由内置 imagegen 依据现有获认可画稿扩展，再经 Blender 建立平面场景。没有新 Studio 生成、积分消费或软件安装，不能把原创画稿标成新 Tripo 三维模型。

当前为地图制作阶段：其余区域仍有通用群落，未全部达到首四区布置密度。室内 / 居民、寺观 / 洞府、区域生态 / 无缝事件、队伍战斗、约 15 分钟完整战役、全系列迁移、新水墨怪海及实体手机尚未验收。整体美术审阅继续进行，不以构建或通行脚本通过代表用户视觉认可。

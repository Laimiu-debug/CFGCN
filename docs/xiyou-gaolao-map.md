# 高老庄田庄与林木

2026-10-20，接续 [河岸表面精修](xiyou-bank-surface.md)，继续地图优先。保持已确认水墨与平面皮影、无道路导向、探索留白和当前开发版画面优先。制作的是可探索村庄外景，不含八戒收服、村民、室内、种田经营或新地图完整战役。

## 改编依据与空间

[原著第十八回](https://zh.wikisource.org/zh-hans/西遊記/第018回)描写高老庄的村舍、竹篱、野树、杨柳及春日桃杏。这里据此组织村庄，不声称复原真实地理、古建形制或具体物种。具体位置、尺度、田畦和绕行空间为原创游戏改编。

原高老庄只有通用地形与散树。本批新增 16 栋民居、一个高宅庄门、8 段竹篱和 8 片田畦，组合为主宅、小院和田边草舍；地图地标合计 68 处，民居 / 僧舍由 31 增至 47 栋。花树、柳、竹、阔叶分组布置，实际 256 米地图采样中保留 9 株杏树；不是所有原始候选点都直接入场。数量不是同屏数量或各自独立下载数。

首轮 V24 游戏画面显示，主宅与侧屋离到达镜头太远，开场只有孤立庄门；该画面没有标成完成。随后将主宅 / 侧屋与庄门收拢，把两处田畦和两株杏树移入近景，外围草舍继续供探索。原稿、V23 改前与 V24 过疏对照保留，实际构图仍以最终游戏画面审阅。

- 主宅庄门中央是真正透明的开口，可见侧墙 / 门柱保持实体；门内前庭、屋侧与屋后留出行走空间。屋舍和庭院找平共用地形，出生落点继续保留。
- 竹篱是有端头的短段，前后和端部可绕。实跑发现 V26 庄门与竹篱的缝隙扣掉角色身体后过窄，已加宽两侧可见缺口，并加入缺口连续穿行与有效宽度检查。田畦可穿行，野生树石避让实际种植范围，未清空引导道路。
- 根点、建筑脚部、地基、庭院和田畦来自 `packages/game-core/data/xiyou-map-layout.json`；图形地图读取相同位置与角度，新增场景缩图，田畦用稀疏笔触表示，未探索仍留白。

## 资产与实现

三幅新画稿为高宅庄门、竹篱和杏树，内置 imagegen 根据已认可民居 / 阔叶画稿原创扩绘，经现有 Blender 5.2.2 制成三场景共用 GLB；详见 [画稿 / 提示词与来源](../apps/xiyou/art/ink-gaolao/README.md)。沿用已接收 Tripo Studio 民居 / 植被类别原型与投影作为参考，没有新 Studio 生成、积分消费、软件安装或覆盖原型，不称新 Tripo 三维模型。

原画、三份完整提示词、裁切 / 根部锚点 / SHA-256、RGBA 图集和可编辑 `ink_gaolao.blend` 保留。新包 `ink_gaolao.glb` 为 3,431,368 字节 / 6 三角面 / 一材质 / 一图集；当前开发版保留画质，不以此作加载速度或怪海性能结论。建筑 / 树木复用既有模块，程序地形与田畦笔触明确是基础。

新植被变体在 Rust 物件、真实树根、渲染和地图图集保持一致；新场景接入资源清单、持久缓存与失败处理。田畦世界坐标预计算复用，避免增加地面 / 物件采样时反复查找区域与计算布局锚点。正常 HUD 无新常驻文字框，制作定位仍只在显式调试入口。

# 西游地表与郊野村居

2026-10-20。接续首四区地标，继续 M3 地图精修和水墨 / 平面皮影方向。本轮把长安郊野的一段支路、院落、两栋民居、庭前 / 庭后柳与两片菜畦组成可实际行走的空间；同时调整地表采样，减少固定图案重复与陡坡拉伸。当前仍是本地样板，村落、寺观、洞府与整个西游地图尚未完成。

## 地貌、地表与空间

原地表使用同一画稿约每 14 米重复，坡面主要按世界水平坐标投影，明显的草纹会重复、侧坡会拉长。现在水墨地表保留原有四幅画稿，以连续变化的世界坐标偏移混合两次采样；陡坡岩层结合水平与两个侧向投影。静态地表没有新增后处理、整屏墨雾或单独材质 / 网格；远处依然使用 mipmap 和现有纸色雾。画稿本身仍会复用，不能将这种处理称为无限独特绘画。

每种地表按实际权重采样；静态草地通常两次画稿读取，混合土路、河滩与陡坡时会增加采样，须以实际帧时间检查，不能因没有新模型就宣称零成本。旧战斗样板保留原地表路径。

院落中心约为世界坐标 `(-32, 68)`，通过约 40–80 米段的短支路接到古道。布局保存在 `packages/game-core/data/xiyou-map-layout.json`：

- `courts`：共用地面找平，边缘平滑回原坡地；房屋、树根、可走地面仍共用真实高度。
- `lanes`：院外支路和院内转折同时用于地面与附近地图；附近地图只加一个村居图形，不给每棵柳树额外文字标牌。
- `landmarks`：两栋房屋与两株柳共用模板；只有可见墙脚、石基与树根阻挡，院子和屋侧可走。树冠与透明画稿空白不形成墙。
- `fields`：菜畦边界、朝向写入已有地面的 UV；细行列使用地表笔触表达，远处衰减，无新增草叶实例、纹理、网格或碰撞。当前只是静态环境叙事，不包含种植经营。

实际初稿已能从出生点走入并绕屋，但画面仍像空地上的两栋房子，故继续加入庭后柳树与菜畦，不以通行检查通过作为视觉完成。首屏主路与四向空间保持开放，地图位置和旧战斗存档仍独立；被新布置覆盖的旧点沿用附近安全恢复。

## 来源与制作

复用已接收的 Studio 民居和河岸原型，在 Blender 做正交投影，再分别由内置 imagegen 原创水墨修绘；没有新的 Studio 生成、积分消费或软件安装。民居修正原模型的破碎表面并采用闭合门板、三开间与清楚石基，保留克制设色；河岸参考树偏棕榈形，只取体量参考，柳树另修成垂枝与叶组，不将原模型称为合格柳树。

来源和两份完整提示词在 `apps/xiyou/art/ink-hamlet/`，说明见该目录 `README.md`。两份透明原画及哈希保留，`prepare.mjs` 只打包图集，`build.py` 在 Blender 制成面向既有镜头的两个场景并保存可编辑 `ink_hamlet.blend`，`check.py` 在独立 Blender 中重导入。

运行包 `ink_hamlet.glb` 为 126,088 字节 / 4 三角面 / 一个材质 / 一张 768×1024 图集；打包 PNG 为 123,660 字节。GLB SHA-256 为 `195df71a70ed251d97a4f4923e3ad35f10753bc2cb149d7469e30d8239ed5278`。人物、原 Tripo 文件与此前地标源未覆盖。房屋是原创文学游戏意象，不是历史古建复原；当前没有室内、居民、剧情、物品奖励或经营功能。

最终首屏场景原始内容为 1,089,721 字节，仍在 1.5 MB 场景预算内；其中新增包 126,088 字节，另有地表 shader 增量。引擎 WASM gzip 6,151,300 字节另列，门户与字体不在上述场景合计内。资源重复摆放不重复下载，但每个实例与地表采样仍有绘制成本。

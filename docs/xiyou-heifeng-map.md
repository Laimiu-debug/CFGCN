# 黑风山山寺与洞口

2026-10-20，接续村居 / 林木扩充，继续 M3 地图精修。地图仍无道路导向，沿用统一水墨场景与皮影人物、图画优先和实际脚部碰撞；当前开发版以画面 / 布置为先，不按旧首屏上限压缩新图。

## 文学依据与实现范围

原著[第十六回](https://zh.wikisource.org/zh-hans/西遊記/第016回)写观音禅院的殿阁、钟鼓楼、松竹等环境，[第十七回](https://zh.wikisource.org/zh-hans/西遊記/第017回)写黑风洞门前及闭合石门。本次选取山门、正殿、钟亭和闭门洞口构成原创游戏外景；空间尺度、地理位置和画稿是改编，不作为真实古建、考古遗址或原著完整复原。

黑风山区域增加一片可往返的山寺院落和相邻洞前空地。山门的透明开口、钟亭柱间可穿行；正殿木门、低院墙与洞口石门为可见实体，保留脚部碰撞，两侧可绕行。洞门不能画成深黑开放洞穴却在前面加无形阻挡。本轮没有室内、洞内、火烧禅院、袈裟事件、熊罴怪或任务交互，待地图组合之后接生态与事件。

## 布置与共源规则

- `packages/game-core/data/xiyou-map-layout.json` 加入山门、正殿、钟亭、洞口和两段低墙，并复用两栋民居作僧舍；寺院 / 洞前局部找平与手工林石群共源。实际位置、脚部矩形、入口让行和地图缩图共源；出生与自由探索保留，不重新清空整条主路线。
- 正殿在院落后侧，钟亭偏一侧，门侧低墙与两间僧舍交代内外空间；松竹、阔叶与石组在院外形成不对称层次。实际镜头发现首版过空后已拉近殿 / 钟亭，并在院内加入局部石板铺地。石板复用既有地面 UV、笔触与材质，无额外地砖模型，不延伸为院外道路。
- 首版洞口像孤立摆件，已增加后侧真实山坡及岩组。山坡编码于同源地形高度采样，人物、网格、接地与地图都读取它；属于明确标注的程序地形基础。寺院与洞口之间是自由地貌，不画引导路线。入口前树石与对应碰撞共同让行；远处地块继续按邻近窗口回收。
- 缩图使用同一原画，跟随实际行走揭图，未探索内容保持留白。正常界面没有区域传送；新增三处定位仅在显式制作工具中出现，用于门口 / 钟亭 / 洞门检查。
- 来源为既有已接收 Studio 建筑与山石类别原型 → 内置 imagegen 水墨扩绘 → Blender 平面布景 / 可编辑源。详见 [原画与完整提示词](../apps/xiyou/art/ink-heifeng/README.md)。没有新 Studio 生成、积分消费或软件安装，旧神龛资产和功能不改动。

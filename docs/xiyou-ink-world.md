# 西游水墨地图样板

2026-10-20。继续地图优先，执行 `art-direction.md` v2 的水墨与平面皮影方向。当前是实际游戏内的首轮场景样板，包含地面、山松、山石、低矮地被、河岸与既有皮影悟空；完整地图、正式叙事地标和战役仍在制作。

后续已加入 [首四区地标样板](xiyou-map-landmarks.md)：路亭、石峡、五峰和路石共用约 101 KB 包，首屏场景增至 960,482 字节。以下数值保留本轮地面 / 树石 / 河岸的历史验收口径；最新地标的加载、通行与资源证据单独记录，不覆盖先前结果。

## 空间与画稿

地形仍使用真实世界坐标、起伏和相同的可走采样。场景布景本轮采用面向既有俯视镜头的水墨平面网格，脚点落在地面上；人物、山松、树石可前后遮挡，遮住主控的布景采用有深度写入的裁切退让。此组合是可运行的承载样板，不把全系列最终采用平面布景或三维场景擅自定稿。

地面由一张原创淡设色图集表达草地、土路、岩层与河滩；保留笔触与稀疏留白，减少旧地表的密集草叶与摄影纹理。长安、双叉岭、五行山与鹰愁涧的到达镜头加入小片手工编排的松林与低石组；其余周边继续复用确定性群落。通行与可见根部、石脚共读布局，不把树冠当成全幅阻挡，低矮地被可穿行。

河道有曲折和宽窄变化，实际地面、水面、碰撞与附近地图共用 `packages/game-core/data/xiyou-map-layout.json` 的参数。渡口保留略低于水面的浅滩；首轮实际画面发现水面太淡、像云雾，已加强深水与浅滩的明暗 / 青色差异，远水保留可见轮廓。水面流动取模拟时钟，暂停时随人物一同停止。

## Tripo 来源与制作

本轮复用已接收的 Tripo Studio 树木、独立山石、松岩和树冠地被原型，没有重新生成或消费 Studio / API 积分：

1. `render_sources.py` 在 Blender 投影既有模块，原始 GLB 和 Studio 记录保留。
2. 内置 imagegen 参照投影做原创水墨修绘，并单独制作地面画稿。布景初稿的排版不便切分，保留初稿，另生成有隔离空间的版本。
3. `prepare.mjs` 检查透明边界，记录四个画稿窗口，缩放与打包运行图集，不重绘原始像素。
4. `build.py` 在 Blender 制作平面布景与 UV，保存可编辑 `ink_scenery.blend`，导出一个材质、一张贴图、四个 glTF 场景的共用包。运行时实例复用场景与材质；透明背景裁切并写入深度，不给每棵树新增透明整屏层。
5. `check.py` 在新开 Blender 中重导入全部场景，核查落脚零点、平面尺寸、UV、三角面、材质和源哈希；再以实际地图画面核查。

全部画稿、投影、提示词、脚本及来源 / 运行哈希在 `apps/xiyou/art/ink-world/`，可编辑文件为 `apps/xiyou/art/source/ink_scenery.blend`。使用的三份完整提示词为 `terrain-prompt.txt`、`scenery-prompt.txt` 与 `scenery-layout-prompt.txt`。此流程包含生成式修绘，不是三维自动压扁，也没有调用 InkTool 或 WooooShadow 制作这些场景。它验证场景画稿加工，不证明 Tripo 人物到合格皮影关节角色的转换已经通过。

## 续存与通行

场景改版可能使旧落脚点落在新树石或水域内。现在优先恢复原位置；受阻时搜索附近安全地面，保留所在区域和已探索记录，不重置到长安。模拟状态明确返回请求的原位置，网页确认恢复后保存实际落脚点，避免位置变化导致持续等待恢复确认。

地图与旧战斗存档继续分开。真实网页测试中的树根和深水两个旧点均只平移约 1.5 米到安全处，再次刷新保持落点，旧战斗记录逐字节保留。

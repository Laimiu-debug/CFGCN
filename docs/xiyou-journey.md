## 角色成长

| 角色 | 本轮技能                             | 定位                                         |
| ---- | ------------------------------------ | -------------------------------------------- |
| 唐僧 | 梵音退敌、锦襕护持、回春愿、心灯引路 | 范围退敌、队伍减伤、恢复、灵光吸取与领队移速 |
| 悟空 | 如意棍法、定身咒、毫毛分身、火眼金睛 | 自动近战、控制、分身和护队范围               |

全队只使用 Run.xp / next_xp 一条灵光。两人的拾取进入同一经验池；升级冻结战斗与计时。唐僧独行时直接选其技能；悟空入队后先选角色，再从该角色的三张卡中选择。每次升级同时锁定两人的候选卡，返回换人不重掷。每项常驻本领最高五级；“调息整备”恢复两人气血，可以重复选择。新悟空自带棍击与定身，避免必须先分配升级才有作用。

区内跨路段继承等级、剩余灵光与两人的修习；切换时恢复气血。本轮临时失败条件仍为唐僧或已入队悟空气血耗尽，失败可重试本段；永久倒地、救援和跨大区重置规则尚未确定。

鹰愁涧将队伍扩展为三人：小白龙四项修习为踏浪蹄击、游龙疾行、龙鳞护佑、清流回响，对应自动近战、踏浪冲刺、队伍减伤与水波远击。经验仍只有一条，三人的候选技能同时锁定，换培养对象不重掷。白龙马踏水不减速；其他角色在涧水区域（z=24–30 且离石汀中心超过 3 米）减速并受轻微伤害，龙鳞护佑可暂时保护全队。伙伴会尝试走石汀。已入队白龙马气血耗尽也触发当前原型失败规则；永久倒地 / 救援仍待决定。

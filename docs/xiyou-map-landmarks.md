# 西游首四区水墨地标样板

2026-10-20。继续地图优先，沿用 `art-direction.md` v2 的水墨与平面皮影方向。在既有可探索地图中加入长安路亭、双叉岭石峡、五行山五峰遗址与鹰愁涧路石，让区域有可辨识的画面落点。当前是本地运行样板，场景承载形式、画稿和全图最终美术仍待审阅；新地图尚未整合区域怪物和约 15 分钟完整战役。

## 四处布置与通行

| 区域     | 地标     | 空间处理                                                       |
| -------- | -------- | -------------------------------------------------------------- |
| 长安郊野 | 木构路亭 | 柱脚有实体碰撞，亭内可进入；入口前的手工与散布树石共用让行范围 |
| 双叉岭   | 石峡     | 两侧石脚阻挡，拱口透明处可双向穿行；不以整幅画稿作墙           |
| 五行山   | 五峰遗址 | 以五峰剪影和赭色空白封印意象表达故事，放在古道侧面，保留主路线 |
| 鹰愁涧   | 涧口路石 | 浪纹石与芦草放在干岸，脚点与地面贴合，留出渡口与横向岸路       |

这四处为原创文学游戏改编，不声称真实古建、历史遗址或原著精确地理复原。封印画稿不使用伪造的经文字样，剧情、救援演出与功能仍按后续事件模块制作。仅投影已有神龛建筑资产作屋顶 / 立柱参考，没有恢复当前暂停的神龛修模或技能工作。

地标尺寸、位置、脚部矩形与可选入口范围保存在 `packages/game-core/data/xiyou-map-layout.json`，Rust 布景、地形、通行与 React 地图图形读取同一布局。只在实际柱脚 / 石脚加角色身体半径；附近地表按同一脚点找平、混合回原地形并烘入静态接地影。图集透明部分裁切且写入深度，遮住主控时沿用现有布景退让。

画面与实跑曾发现三项问题，修正前证据保留在 `.local/qa/`：路石落在河岸过渡而悬空，已移至干岸；石峡 / 五峰在到达视野内截顶，已调整位置及五峰尺寸；路亭前一块手工石和一块散布石堵住入口，已调整布置并加入明确的树石让行范围。让行会移除实际布景和对应碰撞，不能只绕过碰撞而留下石块。

## Tripo、画稿与 Blender

使用已接收的 Studio 建筑、树木与山石代表资产作造型参考；完整来源、项目 ID、原件哈希与已有制作记录保留。当前 Studio 资产页读取曾超时，没有新的模型生成、积分消费或软件安装，也没有改动原有 Studio 资产。

1. `render_reference.py` 在 Blender 正交投影既有建筑，保存参考图和来源哈希。
2. 内置 imagegen 参照建筑投影和已有松石投影，制作四幅原创淡设色水墨画稿；完整提示词保存在 `prompt.txt`，原件为 `source-v1.png`。
3. `prepare.mjs` 根据透明边界切分、缩放与打包 768×768 图集。石峡锚点按实际拱脚开口定位，保留打包记录，不把整幅画稿的矩形中心当成通道。
4. `build.py` 按共用布局尺寸在 Blender 创建四个平面布景，保存 `ink_landmarks.blend` 并导出共用 GLB；`check.py` 在独立 Blender 进程重导入所有场景，核查尺寸、足底、材质、UV 和三角面。

源目录为 `apps/xiyou/art/ink-landmarks/`，可编辑文件为 `apps/xiyou/art/source/ink_landmarks.blend`。这是包含生成式修绘的制作流程，不能写成 Tripo 自动产出合格水墨布景、纯投影或角色专用转换已通过。

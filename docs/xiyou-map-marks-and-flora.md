# 探索地图、个人标记与低矮植被

2026-10-20。用户要求继续完善树、小草、花，按 M 开地图、做个人标记，雾气遮盖未探索部分，改变“只有树和红点”的地图图形。沿用统一水墨 / 平面皮影、无道路导向、开发版画面优先与 Tripo 原型来源保护。

## 当前实现

- M 从页面、地图对话层或获得焦点的 WASM 画布开关；同源 / 窗口来源校验继续有效，长按重复、组合键、输入框和输入法组合不触发。开图停止移动，关图按打开前的行走 / 暂停状态恢复，Escape 同样收图。
- 旗帜按钮进入落标模式，点击已探索处落标；方向键平移地图，Enter 在视野中心落标。选中旗标可删除，按钮可撤销最近一次删除。拖动、第二指、取消或在画布外松手不落标。最多 64 个，独立版本键 `cfgcn:map:xiyou:marks:v1` 保存；原位置 / 探索 / 旧战斗存档不变，损坏或禁止存储时仍能使用并显示保存状态。
- 16 米探索格继续只随实际角色移动揭开，拖动 / 缩放 / 标记不揭图。世界锚定静态墨雾覆盖未知地势、建筑和植物；图形不因拖到远处提前暴露。地貌等高线取真实 Rust 高度交点，林地用俯视林冠 / 竹叶与花草笔记，建筑 / 寺洞保留实际画稿缩图与少量地名，田畦 / 水面共源。当前位置直接使用当前皮影悟空的真实头部分件，个人标记用可键盘选择的旗标。
- 三张原创低草、野花、蕨丛画稿接入同源群落：林下与空地形成不规则小片，避开深水、田畦、庭院和实体脚部，可自由穿行。既有树种、岸柳、杏树、47 栋民居 / 僧舍与 68 处地标保留。本批没有新增高大树原型，主要改善林下与草花层次。
- 低矮植物由一个共用 RGBA 图集按地块合并成一张网格，随 5×5 地块窗口释放；每丛两个三角面，两个底角分别贴实际地形。Blender 源 / 三场景 GLB 保留，运行直接复用同图集与测定尺寸，避免重复加载图集。

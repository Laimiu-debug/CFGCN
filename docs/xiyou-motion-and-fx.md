# 西游移动、动作与法术

2026-10-20 当前五人皮影修订：六十招取消自动根位移、起跳和停步；移动中保留腿部，独立空格 / 触屏闪避可取消未释放段落并保留技能冷却。新比例按各角色分区修改骨架与网格，再求解足底；头与尾 / 行囊加入滞后收势。模型尖端经过逆绑定矩阵转换后由实际 `GlobalTransform` 采样尾迹。技能分蓄势、方向主体、真实接触、余势四段，复用六种专属轮廓与既有笔触材质；细节见 [五人演武 v5](xiyou-shadow-trial.md)。两类场景抖点透视已移除，保留透明原图裁边和实际深度。静态材质不再逐帧通知修改，游戏帧间隔与模拟 CPU 耗时分别记录，不能用录像时基作性能证明。

本页保留旧 Tripo Studio 立体角色的移动与法术实现记录；当前正式美术方向以 `art-direction.md` 的水墨与平面皮影为准。皮影技能动作模块的新制作与接入接口见 [皮影动作模块](xiyou-shadow-actions.md)，不将旧立体角色的五段动画或法术效果标成皮影技能已完成。

旧立体样板沿用经 Blender 修整的骨骼和五段动作；该历史轮次没有新生成模型、购买 API 积分或安装软件。弧带、莲瓣和丝带是特效表面，复用已有原画，不冒充新的 Tripo 实体模型。

- [幻灵战队官方技术复盘](https://www.riotgames.com/en/news/the-tech-behind-swarm)：逐只寻路、怪物聚团、粒子和阴影都可能成为瓶颈。这里采用共享三维动作、空间桶和有上限的特效；没有把官方的流场导航写成自己已经实现的功能。
- [Halls of Torment 开发者访谈](https://w4games.co/blog/w4-games-news-2/interview-with-chasing-carrots-developer-of-halls-of-torment-47)：开发者明确选择预渲染的九十年代画面。这里借鉴按固定游戏镜头控制成本的取舍，人物与群怪仍保留三维，不照搬其美术或声称已复现其内部算法。
- [Riot 对战斗清晰度的说明](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)：攻击方向、技能的重要程度与命中范围应可识别，视觉噪声需要限制。应用到西游时，身体施法、飞行方向、命中反馈和首领危险边界各自承担含义，不能统一替换成脚下圆圈。

## 行走修复

实机复现：画布内按住 W，再用鼠标点击技能，按钮在按下时取得焦点，Bevy 随即清空按键；人物提前停止。战斗按钮现在阻止鼠标按下抢焦点，正常 click、键盘激活、触屏多指处理和冷却禁用保留。失焦、离开页面、触控取消与暂停仍要停止移动。

旧实现每次在待机、走路和攻击间切换都停止全部动画，移动攻击还会整段替换腿部。新实现按实际水平位移推进步态，保留循环相位，以 90 毫秒的模拟时间混合姿势；人形的骨盆 / 双腿和马的腿蹄使用独立遮罩，上身施法不打断移动中的腿部。静止时保留完整施法动作。暂停和培养停止姿势时间及混合权重，不依赖独立的墙钟过渡。

镜头的位置与朝向共同跟随同一个平滑焦点，使用指数跟随保持不同帧率下的节奏一致；固定俯角避免坡地上“位置滞后、朝向立即变化”造成的俯仰晃动。角色转身也做短过渡，不改碰撞位置或操作速度。

隐藏的分身、未出现的龙形灵相和零权重动作停止骨骼求值，需要时复用原骨架并从当前模拟姿态与步态相位重新接入。保留资产引用不代表持续运行动画；不能为没有出现在画面中的角色支付完整动作成本。

法术使用五个共用曲面网格和四种共用颜料材质。棍风、水浪和莲瓣把已有重彩原画映射到弧面；掌线与弹尾保持连续轮廓。水幕具有独立的竖向曲面及正确包围盒，不能把平放的同心线当水浪。全局最多 96 个活动 / 回收特效实体，近处小命中装饰最多 8 组，减少动态时降为 4 组。每个表面 40 三角面，不逐粒建立物理、骨骼或独立材质；角色动作和主要技能优先于小命中装饰。菜单用透明小实例预热共用特效管线。

大面积脚下法术铺片已移除。脚下只保留接地影、当前领队标记与真实敌方危险范围；危险边界仍对应伤害半径，不能因装饰扩散而改变。法术和动作使用模拟时间，暂停 / 培养均冻结。减少动态保留施法和重要命中，减小装饰扩散、上升、旋转和同时出现的细节。

战斗伤害、成长、冷却和正式刷怪上限沿用现有规则。动画、特效与实际战斗需同镜头审阅，不把调用成功或静态截图当作动作质量已获用户认可。

## 实机验收

`crowd-benchmark` 下增加仅本机测试使用的动作探针；正式客户端不编入逐帧探针。实际记录骨骼变换、腿部遮罩、步态相位、镜头、暂停和特效上限，避免只检查“动作名字存在”。用正常键盘持续移动并点击六个技能，另跑多指触控、完整救人与跨区路线、资源缓存、200 / 500 / 1000 怪海和受控加载。性能条件和硬件边界见 `xiyou-performance.md`。

已构建正式门户及 `optimized` 实验客户端后，用 `npm run check:xiyou-motion` 重跑动作浏览器检查。需要本地 Playwright / Edge，可用 `CFGCN_BROWSER_RUNTIME` 指向已有 `node_modules`。脚本在独立浏览器中恢复合法三人行记样本，再用正常按键和六次按钮施法检查实际骨骼、移动、镜头、暂停与特效总量；不修改用户的浏览器行记。逐帧数据、截图和录像写入 `.local/qa/`，它不替代从救悟空开始的完整剧情回归。

具体构建、数据与仍有差距在 Notion 进度页记录；此文是执行规范，不代表最终美术或实体手机已经验收。

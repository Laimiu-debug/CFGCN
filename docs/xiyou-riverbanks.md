2026-10-20，接续村居 / 林木和黑风山外景，继续 M3 地图精修。统一水墨与平面皮影方向、无道路导向、探索留白和当前开发版画面优先保持；原角色动作库和旧战斗样板分别保留，不以地图原画接入冒充战斗整合。

## 空间与文学边界

原著[第十五回](https://zh.wikisource.org/zh-hans/西遊記/第015回)描写蛇盘山鹰愁涧的峭壁、清涧与涧边草丛；本次据此加强山涧空间。具体柳树、芦苇、卧石种类、位置和尺度为原创游戏改编，不声称原著地貌、物种或季节的完整复原。本轮没有新增白龙交互、收徒动画、妖怪刷新或渡河剧情。

原镜头岸边较空、植物与其他区域相似。本批加入斜生岸柳、芦苇和低矮卧石三个原创画稿，从同一地形 / 河道布局派生两侧岸线组合；疏密与空隙保持探索空间，不沿河种出连续不可过的树墙，也不恢复引导道路。

当前约 360 米河岸范围两侧合计新增 8 株岸柳、114 丛芦苇和 25 组卧石，数值来自实际 Rust 布置采样；不是同屏数量，也没有把重复实例写成各自独立下载或新 Tripo 生成。原有柳 / 松 / 阔叶 / 竹和村落仍在。

## 实现

- `xiyou-map-layout.json` 的 `shores` 明确当前精修区域与范围；以真实曲流、河宽与岸侧确定根点，分组混合柳、芦苇和卧石，跨地块确定性复现。原有村落 / 林群 / 浅滩继续保留，近景模块与远处回收共用现有窗口。
- `MapProp` 明确可穿行的低矮植被与实体树根 / 石脚；芦苇不因为一张透明画稿获得隐形碰撞，也不使用高树的大阴影。岸柳按底部加权根点导入，卧石为低宽轮廓；实际接地和覆盖仍需游戏镜头审阅。
- 实际镜头发现卧石原圆形占地偏厚，已改为宽而浅的石脚椭圆，保留角色身体余量；加入接近石脚前仍可走的检查。芦苇进一步分成两三丛的错落小片与间隔；水墨水纹由整齐平行斜线改为断续弯曲笔痕，暂停 / 减少动态继续沿用模拟时钟。
- 地图直接读取实际 Rust 物件的图形索引、根点和尺度，新三幅缩图接入同一地图图集 / 内容哈希；不另画虚构岸线或未来剧情路标。正常入口继续隐藏制作定位。
- 复用已接收 Studio 植被 / 山石类别原型与既有认可柳树画风，经三次内置 imagegen → Blender 三场景共用图集；原件、提示词、哈希、可编辑源及新开重导入记录保留。没有新 Studio 生成或积分消费，详见 [美术制作记录](../apps/xiyou/art/ink-river/README.md)。

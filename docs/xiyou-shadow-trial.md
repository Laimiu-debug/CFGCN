## 已接入

- 五位主角各十二个兵器 / 主动技能，分别装备四个不同技能，整队二十槽。被动、成长分支和连携不凑数。十二招机制说明与取舍见 [技能构筑](xiyou-skill-loadouts.md)。
- “十二招整备”暂停战斗，点槽位后换招；已装备的招式交换位置。冷却按技能身份保存，换槽与切人都不刷新。领队可用图标或 1–4 手动接管，Q 或头像切换，WASD / 方向键移动，Esc 暂停。
- 四名伙伴自主接近目标、保持间距、避开已锁定落点。治疗读取真实缺血，护持 / 护弹读取威胁，打断预留短暂意图，减少同一蓄势上重复交技能。号令优先集火但不传送队友。
- 六十招动作的起手、释放与收势实际驱动战斗事件；近击、窄线、双段、拉拽、减速带、放置护持、护弹、有限分身、治疗、净化、标记、条件反击、蓄震、位移、水痕消费都有首轮逻辑。
- 飞棍去回各结算一次，离手期间身体不能并行执行其他棍招；地图中使用空间兵器，回手按原动作时点结束。空格挡不反击，侧后 / 重击绕过正面格挡；因果印按真实扣血触发且一次消费。硬控递减，重敌只破势，治疗与愿契不会复活已倒下角色。
- 位移逐步检查现有地形 / 实体，近击检查遮挡，玩家和伙伴不能直接穿墙瞬移。人物仍保持面向镜头的皮影片，横向翻面与地图方向分别处理。走路相位跟随实际移动距离，按各人已导出的步幅限制步频；短跃和站定动作保留完整身体。
- 使用当前 v4 真实 GLB 与六十张透明动作图，保留八人的原始比例和历史源件。HUD 为透明头像、细血条、技能图与冷却描边；技能整备是独立弹层。

演武中的敌人为狼妖、虎妖、白骨夫人，先使用各一种基础进攻；资源库中的十八种妖怪招式没有全部接入 AI。当前上限为十六名敌人、三十二个地带、两个分身、七十个短笔触；渲染共用材质 / 网格并复用最多一百九十二个效果实体。预警先分配，装饰预算不删除真实伤害。

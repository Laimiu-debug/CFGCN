**90 项：40 主角主动 / 兵器技、20 被动、18 妖怪招式、12 连携；58 项演员技能动作。**

建议每人从 8 招选择 1 自动兵器技 + 2 主动技；被动随成长选取，连携按队伍条件触发。不是给手机同时摆 8 个技能按钮。

普通敌人选择 1 普攻 + 1 特技，精英选择 2 特技，首领按阶段选招。六招是招式库，不同时无间隔释放。

本轮不确定最终伤害、冷却、半径与成长数值；动作时长为演练数据，不能代替实战平衡。

实际开发边界：保留现有地图 / 战斗 / 存档。动作有起手、接触、收势与空间接点；技能特效、命中、异常、AI 和数值接入不由动画文件自动完成。

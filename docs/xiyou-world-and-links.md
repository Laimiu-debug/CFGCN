# 西游连续地图与队伍连携

2026-10-19。五行山—松风古道—鹰愁涧已实现为同一 Rust 世界中的可往返片段，角色、经验和个人冷却过界时持续存在。长安与双叉岭仍保留两段教学；完整长安至灵山尚未连接。实际验收与加载数据保存在 Notion 进度页及 `.local/qa`，不把设计方案当作完整大世界。

## 地图与事件

山地区域约为 z=-3–40，松风古道为 40–58，鹰愁涧从 58 延续至 108；河岸资源整体偏移 64 米。五行山封印在 (0,18)，愿印在 (0,82)，浅汀为 z=88–94、中心 x=-3–3，渡涧路标在 (0,102)。这些是游戏空间，不代表原著真实距离。

小怪在队伍附近生成，依出生地区保留外观和行为。离队伍超过 30 米的小怪移除，远处拾取物也有清理范围；首领保留，并在队伍离巢超过 22 米后返回。已完成的事件不会重生首领、重复收徒或增加一条“获胜局数”。解封和点化保留短暂停顿说明，区域边界没有结算或传送。

## 伙伴独立行动

1 / 2 / 3 或真实模型头像切换当前领队，不改变各人的位置、气血或冷却。其余成员在约 13 米范围选择目标，按角色保持攻击站位、避开预警、彼此分离；脱战后松散归队。个人空间和决策间隔避免三人重叠。

可见山石及松岩模块的位置用于导航与碰撞。伙伴在需要绕路时计算有限的网格寻路，并使用石汀渡河；不再靠对着石头直走或瞬移归队。寻路有节点上限、较低更新频率和直线路径快路。仍需继续测试复杂战斗与更多地形，不宣称已有任意地形的通用导航网格。

## 共享成长和保存

三人共享一条灵光，升级先选培养对象再选三张本领之一，所有人的候选同时固定，换对象不重掷。现有 12 项人物本领，各最高五级；调息可重复。当前原型等级上限 70，与存档校验范围一致。伙伴一人气血耗尽仍触发本轮失败，倒地救援规则尚待后续设计。

旧 `cfgcn:save:xiyou:v1` 行记继续保留。检查点仍为 version=1，新增可选 `events` 和 `camp`，旧字段默认兼容：

- events 的 1 / 2 / 4 / 8 / 16 位分别是救悟空、守山妖、平息白龙、白龙马入队、过涧，按顺序验证。
- 旧 chapter=2 从五行山开始；旧 3 映射为已救悟空、清理山口并抵达涧边；旧 4 映射为三人已完成渡涧、落在北岸。
- 新世界的 chapter 仅表示当前显示区域；事件与营地决定进度。里程碑和营地保存构筑；同一营地再次休整也会更新新修习，30 秒内不可重复恢复。
- 不保存瞬间敌群、生命值或精确战斗位置；刷新和失败重试回到最近路标。写入失败不覆盖旧行记，在界面显示待保存提示，可恢复写入后点图标重试。

## 四组自动连携

12 项人物本领之外已有四组自动配合，均使用真实命中或支援条件，不额外增加连携按键：

| 组合                    | 条件                                                           | 效果                                                    |
| ----------------------- | -------------------------------------------------------------- | ------------------------------------------------------- |
| 唐僧 + 悟空：金刚破阵   | 同一活目标在梵音标记窗口内实际受到棍击，伙伴相近，独立冷却就绪 | 短起势后范围破阵，获得共鸣；8 秒冷却                    |
| 悟空 + 小白龙：龙腾棍势 | 水波命中留下潮印，再衔接真实棍击，双方相近                     | 水棍范围打击与短控制；10 秒冷却                         |
| 唐僧 + 小白龙：清流护愿 | 伙伴受伤、附近有威胁，护持与龙鳞保护同时覆盖，双方相近         | 恢复气血并延续短保护；18 秒冷却                         |
| 三人：西行同心          | 共鸣满、三人相近且面对精英或成组敌人                           | 三人有起收的合击、范围伤害和短控制；消耗共鸣，24 秒冷却 |

优先处理救急恢复，其次三人合击、水棍、梵音棍击。同一时段只发动一组。目标死亡时尝试衔接附近活目标；没有有效目标或伙伴散开则取消，取消大合击退回共鸣。实际效果发生后才增加触发计数。首领的连携控制最多 0.25 秒，避免永久压制。

连携统一图标、共享共鸣条、角色动作和队伍连线，动作中点与效果时刻对应。换人不刷新资源；暂停与升级冻结时序、动画和预警。减少动态保留功能信息，避免长切镜头。

## 流式资源与启动

角色和共用模块保留，地图根及其子实体、网格和材质引用在远处释放。前往鹰愁涧时提前请求；返回时也预取，使用不同装入 / 移出距离避免边缘反复请求。未就绪时展示铺路提示，可向后探索；资源失败有明确错误和重试。

每个 GLB 先请求根资源，再共用场景与动画句柄，消除同一角色的四次请求和解析。首页不下载河岸资源；旧山门试炼使用自己的旧地图，并独立判断就绪。

本次减去未使用的引擎后处理与查色表，gzip 包约 6.05 MB；采用保留贴图、顶点色和骨骼的轻量绘本材质，避免完整 PBR 材质图首次编译阻塞。下载、解压、编译、初始化、角色根和游戏就绪分别计时；编译缓存可选，受限时退回正常加载，不把缓存命中当作冷启动。

同机本地新 Edge 进程从约 17.4 秒到约 1.5 秒；此前公网约 41.45 秒属于另一条件，不能直接相减。使用旧发布快照与最终新资产、各自全新 Edge 进程，在相同 6 Mbps 下载 / 80 ms 延迟下直接进入游戏 iframe：27.82 秒降至 10.81 秒，无运行错误；这个对照不含外层官网，也不是公网实测。生产部署与真实手机性能单独验收。

## 手机触控与进入路径

手机战斗使用左侧浮动摇杆：手指落点即摇杆中心，小幅漂移有死区，拖动距离控制速度，斜向速度有上限，移出区域仍接收已捕获手指。松手、取消、失焦、隐藏和旋转时清零；暂停 / 升级也会释放捕获，不残留移动。桌面继续支持键盘。

右侧是两枚技能图标，头像直接换人。触控直接处理指针按下，因为一些浏览器不会为第二根手指产生普通点击；兼容点击与键盘触发时避免重复施法。冷却中的按钮保持禁用。触屏不显示 Space / E / Q 提示，保留动作图形及可访问名称；动态视窗和安全区替代原固定最小高度，竖屏与短横屏不需要上下滚动操作战斗。

战斗 HUD 已去掉任务、头像、迷你地图、暂停、计时、经验和状态提示的矩形底板。共用 `portrait` 按钮显示人物与选中金环，下方只有细气血条；地图直接显示山、水、路线与事件。任务信息在区域或事件变化、恢复游戏时短暂显示 3.8 秒后隐藏，区域名与细进度线保留；暂停和交互只显示图标，完整名称通过可访问标签和详情保留。

游戏直达页按需引入首页地图和长安入场，不再连带下载约 720 KB 的首页三维模块（gzip 约 197 KB）；当前基础入口约 249 KB（gzip 约 81 KB）。首页和入场仍可正常显示并交接到真实游戏。

原先编译模块缓存没有在当前 Edge 生效：IndexedDB 不能保存该编译模块。本轮在同一独立缓存库中回退保存 WASM 字节，读回校验文件名版本、大小、魔数、SHA-256 前缀及入口导出，再编译。只保留一份引擎；不动行记。编译模块支持的浏览器仍优先保存模块。打开库受限 / 超时、损坏条目或配额失败均退回网络。实测关闭 HTTP 缓存后重访命中字节缓存，未再请求 WASM；记录区分 bytes 与 compiled 命中。

参考项目于 2026-10-19 重新核查：[小王子](https://littleprince.dev/)公开代码使用 Unity / WASM、Brotli、按哈希分包及持久缓存，并明确目前只支持电脑；[PokéBonk](https://pokebonk.com/)公开入口把语言、主游戏和 Three.js 动态拆开。部分构建资源返回 403 / 读取超时，未取得两者同条件的完整首次可玩计时，不能据此声称两者整局只有几 KB 或一定在手机上秒开。

本作当前首开的主要体积仍是 Bevy 渲染引擎：6.05 MB gzip 在 6 Mbps 下仅传输就需约 8 秒，后面还有人物与初始化；单靠降低模型精度不能消除这个下限。继续改善首开须减少引擎与首区必需资源，不能把缓存重访时间当首次加载。当前域名核对仍为旧包 `client-2b7d8c1f25b5.wasm` / 7,519,096 字节 gzip；本轮与上一轮的本地优化均未部署。生产与真实手机性能分别验收，具体证据见本轮 Notion 记录。

完整网页路径另做受控模拟：中文、390 × 844、DPR 2、6 Mbps / 80 ms、4 倍 CPU 限速，首次至游戏就绪 16.15 秒，缓存重访 2.25 秒；包含外层入口和字体，不能与前面的纯 iframe 成绩直接相减。它是桌面 Edge 的模拟条件，不能标作手机真机成绩或首开秒进。证据为 `.local/qa/mobile-load.json`。

后续技术验证建议是保留现有 Rust 规则核心与存档协议，评估更轻的浏览器渲染层，同时复用现有 GLB、骨骼和动作，以减少首开引擎体积。该方向尚未替换当前 Bevy 渲染器，也没有给出未经实现的速度承诺。

## 连续地形、河岸和贴地反馈

2026-10-19 场景返工将原平面换成连续高度：山路、缓坡、谷地、弯曲河岸与水下浅滩。几何、Rust 角色高度与 WESL 贴地范围由 `packages/game-core/data/xiyou-terrain.json` 同源生成，角色、敌人、拾取、弹体、血条、镜头和路标取得一致地面高度；二维战斗距离与原存档字段保持不变。水域判定遵循同一河道曲线，伙伴寻路检查沿途水域，优先走浅滩。浅滩在水面以下，保留连续流水。

树木坐标和缩放从 `art/world-props.json` 同时生成导航障碍与运行实例，Blender 烘焙也使用相同记录；河岸树木避开新水线。山体由少量相连的自然岩壁构成，取消鹰愁涧末端整齐一排山石，使用实体岩壁表达当前样板边界。地形装饰延伸不是额外开放的可玩区域。

范围平面细分后依据共享高度在 GPU 贴坡；水中范围位于水面，危险圈外缘对应真实伤害半径。莲华、云尾棍风、水纹及丝线连携取代普通发光几何圈，进度取自规则时钟，暂停 / 升级停止。水面同样使用规则时间；减少动态保留功能预警并停止装饰推进。三位角色的两项主动技已有独立骨骼片段，与原待机 / 行走 / 攻击共五段。

地图使用静态方向投影、环境遮蔽及轻量冷暖体积光照，水面有深浅和透水；不使用重 PBR 图与实时阴影贴图。地形检查逐顶点比对高度，且要求烘焙色为 `COLOR_0`；仍须在实际游戏镜头判断轮廓、重复感、遮挡与手机可读性。本轮画面可审阅，不代表用户已接受最终风格。
